# DH116-V2.0 Joint README

## 概述

适用范围：

- 右手 `DH116-V2.0-R`
- 左手 `DH116-V2.0-L`

说明：

- 本手模型共有 6 个主动关节、5 个从动关节。
- 指尖纹路 / 胶垫 link 为固定件，不是独立运动关节。
- 主从关系公式中的 `x^2` 表示二次项。
- 当前 `URDF` 通过 `mimic` 表达线性主从关系；当前 `MJCF` 通过 `equality joint polycoef` 表达二次联动关系。
- 模型统一使用小写 `link` 命名。
- 左手 `DH116-V2.0-L` 是右手 `DH116-V2.0-R` 的镜像版本：主从关系、量程与公式完全一致，几何、坐标与旋转轴为镜像。

### MJCF equality polycoef

换算规则：

- `y_deg = C0 + C1*x_deg + C2*x_deg^2`
- `c0 = C0 * (π / 180)`
- `c1 = C1`
- `c2 = C2 * (180 / π)`
- `polycoef = "c0 c1 c2 0 0"`

| 从动关节 | 主动关节 | polycoef |
|---|---|---|

## 左右手差异（本型号内部）

| 项目 | 右手 `DH116-V2.0-R` | 左手 `DH116-V2.0-L` |
|---|---|---|
| 主从关系 / 量程 / 公式 | 与左手一致 | 与右手一致 |
| `finger11` 旋转轴 | 约 `(0, 0, -1)` | 约 `(0, 0, 1)`（镜像） |
| 四指旋转轴 | `(1, +ε, 0)` | `(1, -ε, 0)`（镜像） |
| 关节顺序 | 拇指在前 | 拇指在前 |
| 材质颜色 | 白 + 黑 | 白 + 黑 |
