# DH116S Joint README

## 概述

适用范围：

- 目录 `DH116S_URDF_MJCF_Files`
- 左手 `DH116S-L000-A1`
- 右手 `DH116S-R000-A1`

模型概况：

- 共 **17 个 link、16 个 joint**：6 个主动关节、5 个从动关节、5 个固定指尖 link。
- 大拇指有 2 个主动自由度（侧摆 + 弯曲）和 1 个从动弯曲关节；其余四指各有 1 个主动弯曲关节和 1 个从动弯曲关节。
- 指尖纹路 link 为固定件，不是独立运动关节。
- 左右手的 link/joint 命名、行程、联动公式完全一致，仅**关节轴方向**不同（见[关节轴方向](#关节轴方向)）。

约定：

- URDF / MJCF 文件内角度一律为**弧度**；本文档表格中的公式与角度按**度**书写。
- 公式中的 `x2` 表示 `x^2`。
- 所有关节范围均为 `[0, 上限]`，0 位为行程的一端；上限为标定行程（主动）/ 机械上限（从动）。
- `x` = 主动关节角，`y` = 从动关节角；`z` = 指尖角（仅原始数据中出现）。

## 主从关系

### 数据来源

`coupling/` 目录保存原始数据与拟合公式：

| 文件 / 目录 | 内容 |
|---|---|
| `coupling/指节指尖运动关系.md` | 指节角 → 指尖角的二次公式与线性公式（**本模型 URDF / MJCF 采用的公式**） |
| `coupling/连杆指节运动关系.md` | 连杆角 → 指节角的二次公式（机构侧换算，仅备查，未写入模型） |
| `coupling/{拇指,食指,中指,无名指,小拇指}/` | 各手指的分段测量 / 拟合数据（`-指节-指尖-` 与 `-连杆-指节-` 两类 xlsx） |

### 公式汇总

| 手指 | 主动关节 | 从动关节 | 二次公式（MJCF） | 线性公式（URDF） |
|---|---|---|---|---|
| 大拇指 | `finger12` | `finger13` | `y = -0.0008x2 + 0.929x - 0.8639` | `y = 0.8626x - 0.1728` |
| 食指 | `finger21` | `finger22` | `y = 0.0067x2 + 0.8847x + 2.1926` | `y = 1.4238x - 3.7239` |
| 中指 | `finger31` | `finger32` | `y = 0.0076x2 + 0.8485x + 2.0597` | `y = 1.451x - 4.3166` |
| 无名指 | `finger41` | `finger42` | `y = 0.0079x2 + 0.8321x + 2.4732` | `y = 1.4752x - 4.6241` |
| 小拇指 | `finger51` | `finger52` | `y = 0.0075x2 + 0.7349x + 2.0181` | `y = 1.3517x - 4.8982` |

补充说明：

- 大拇指另外还有一个独立主动侧摆关节 `finger11`，它不参与任何联动，可直接控制。
- `MJCF` 使用原始二次公式，通过 `equality joint polycoef` 表达，换算规则：`polycoef = [c0·π/180, c1, c2·180/π, 0, 0]`。
- `URDF` 的 `<mimic>` 只支持线性关系，因此使用线性公式：`multiplier = m`，`offset = b·π/180`（即角度值换算成弧度）。

### 线性与二次的偏差

由于 URDF 只能线性，两种表达在实际行程上存在差异（数值按当前文件计算）：

| 从动 | 线性 @x=0 | 二次 @x=0 | 线性 @满行程 | 二次 @满行程 | 从动限位 |
|---|---:|---:|---:|---:|---:|
| `finger13` | −0.17° | −0.86° | 55.90° | 56.14° | 64.74° |
| `finger22` | −3.72° | +2.19° | 98.79° | 100.62° | 100.27° |
| `finger32` | −4.32° | +2.06° | 100.16° | 102.55° | 100.27° |
| `finger42` | −4.62° | +2.47° | 101.59° | 103.34° | 100.27° |
| `finger52` | −4.90° | +2.02° | 92.42° | 93.81° | 100.27° |

要点：

- 大拇指两条曲线几乎重合（满行程仅差 0.24°）。
- 其余四指的线性公式在起点为负值（−3.7°~−4.9°），从动限位从 0 开始，因此在**会强制限位的环境（如 Gazebo）中会贴到 0**；RViz 不做限位，会显示成轻微反向。
- 满行程处线性比二次小 0.24°~2.39°。

## 关节轴方向

左右手唯一的结构差异，其余（命名、行程、公式）完全一致：

| 关节 | 左手 `axis` | 右手 `axis` |
|---|---|---|
| `finger11` | `0 0 1` | `0 0 -1` |
| `finger12`, `finger13` | `-1 0 0` | `-1 0 0` |
| `finger21` … `finger52` | `-1 0 0` | `1 0 0` |

> 因为轴方向不同，同一个正角度在左右手上对应镜像的物理动作，但**关节值与联动公式通用**。

## 运行 MuJoCo 仿真

```bash
cd DH116S_URDF_MJCF_Files/DH116S-R000-A1/mjcf     # 左手换成 L000

python sim_hand.py                          # 仅仿真
python sim_hand.py --udp                    # 仿真 + UDP 发送主动关节角度
python sim_hand.py --udp --port 12345       # 指定端口（默认 9876）
```

- 依赖：`mujoco`、`numpy`（`pip install mujoco numpy`）。
- macOS 下 `launch_passive` 必须在主线程运行，需用 `mjpython sim_hand.py` 启动；或用 uv 一行解决：
  `uv run --with mujoco --with numpy -- mjpython sim_hand.py`。
- UDP 输出：每当执行器控制值变化时，向 `127.0.0.1:<port>` 发送一条 JSON，包含 6 个主动关节角（度，保留 2 位小数），例如
  `{"finger11": 0.0, "finger12": 12.34, ...}`。

## 已知限制

以下几点为当前文件的现状，未做额外调整：

1. URDF 线性公式在低角度为负值，从动关节无法到达（见上文偏差表）。
2. `finger32` / `finger42` 的二次公式在主动关节满行程时分别为 102.55° / 103.34°，超过从动限位 100.27°，MuJoCo 中会被限位截断 2.3° / 3.1°。
3. 线性公式在满行程处比二次低 0.24°~2.39°，抓握末端姿态会有细微差别。
4. 本型号的 URDF / MJCF 为手工维护；`tools/` 下的脚本目前只针对 DH116 型号。
